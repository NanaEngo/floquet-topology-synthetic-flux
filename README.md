# floquet-topology-synthetic-flux

Public deposit for *Finite-size and loss-profile limits on topological
protection of Wigner negativity in a chiral Floquet SSH chain* (Physical
Review A).

Does topological protection preserve non-Gaussian resources in a driven,
lossy chiral Floquet SSH chain? No: the local Wigner-negativity contrast
between coherent Floquet sectors changes sign with system size, varies
continuously through all three gap closings, and is not restored by
chiral-matched dissipation — a finite-size and loss-profile effect, not
topological protection.
